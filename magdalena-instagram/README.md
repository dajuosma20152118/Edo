# Perfil de Instagram: Magdalena Vítol 🌿🏮

Kit para crear un perfil de Instagram dedicado a las **Fiestas de la Magdalena** (Castelló de la Plana):
nombre de usuario, biografía, imágenes listas para subir, textos de cada publicación y los pasos para
que **el número de teléfono no aparezca** en ningún sitio.

> Instagram no permite crear cuentas de forma automática (pide verificación por correo y captcha),
> así que la cuenta la das de alta tú desde la app siguiendo los pasos de abajo; todo lo demás ya está preparado.

## 2. Crear la cuenta SIN número de teléfono

1. Descarga Instagram y pulsa **Crear cuenta nueva**.
2. Cuando pida el móvil, toca **«Registrarte con correo electrónico»** y usa un correo (por ejemplo,
   uno nuevo solo para el perfil). Así el teléfono nunca queda asociado.
3. Introduce el código que llega al correo.
4. **Contraseña**: mínimo 12 caracteres, mezclando mayúsculas, minúsculas, números y símbolos,
   que no uses en ninguna otra web. Guárdala en un gestor de contraseñas (Google, iCloud, Bitwarden…).
5. Nombre de usuario: `magdalena.vitol` (o una de las alternativas).
6. Sube `fotos/perfil.png` como foto de perfil y pega la biografía.

## 3. Que el teléfono no aparezca nunca

- **Cuenta personal**: Instagram nunca muestra el teléfono en el perfil. Basta con no añadirlo.
- **Si cambias a cuenta profesional** (creador/empresa): *Editar perfil → Opciones de contacto*
  (o *Información pública de la empresa*) → borra el teléfono y desactiva **«Mostrar información de contacto»**.
- **Que no te encuentren por tus contactos**: *Configuración → Centro de cuentas → Tus datos personales*
  y no añadas teléfono; en *Configuración → Seguir e invitar amigos / Sincronizar contactos* desactiva
  la sincronización.
- **Verificación en dos pasos sin SMS**: *Centro de cuentas → Contraseña y seguridad → Autenticación en
  dos pasos →* elige **App de autenticación** (Google Authenticator, Authy…) en lugar de SMS.
  Así la cuenta queda protegida sin dar el teléfono.
- Revisa que el correo de contacto no se muestre tampoco si no quieres (*Opciones de contacto*).

## 5. Editar o regenerar las imágenes

Las ilustraciones se dibujan en `src/posts.html` (SVG + CSS). Para volver a generar los PNG tras
cambiar textos o colores:

```bash
npm install playwright   # si no lo tienes
node magdalena-instagram/src/render.js
```
